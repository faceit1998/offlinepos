What the app is

OfflinePOS is a Windows point-of-sale application. All shop data (products, sales, debts, staff accounts, settings) is stored in a database file on the user's own computer. The developer does not operate any server that receives this data.

Google user data we access

Only if the user chooses to connect Google Drive, the app requests:

  • https://www.googleapis.com/auth/drive.file — to create a folder named "OfflinePOS zaxira" in the user's Google Drive, upload backup copies of the shop database into it, list those backup files, download one when the user asks to restore, and delete old backups created by the app (older than 30 days). The app cannot see or change any other file in the user's Drive.
  • openid and email — to show the user which Google account is connected.

How the data is used, stored and shared

  • Backups go directly from the user's computer to the user's own Google Drive. They are not sent to the developer or to any third party.
  • The Google sign-in token is stored only on the user's computer, encrypted with the Windows user account key.
  • The app does not sell, share or transfer Google user data, does not use it for advertising, and does not use it to train AI/ML models.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

  • In the app: Settings → "Zaxira va Google Drive" → "Uzish" (disconnect) revokes the app's access and removes the token from the computer.
  • Any time at myaccount.google.com/permissions.
  • Backup files can be deleted by the user from the "OfflinePOS zaxira" folder in Google Drive.

Dastur haqida

OfflinePOS — Windows uchun kassa dasturi. Do'konning barcha ma'lumotlari (tovarlar, sotuvlar, qarzlar, xodimlar, sozlamalar) foydalanuvchining o'z kompyuteridagi baza faylida saqlanadi. Ishlab chiquvchida bu ma'lumotlarni qabul qiladigan server yo'q.

Qaysi Google ma'lumotlariga kiriladi

Faqat foydalanuvchi o'zi Google Drive'ni ulasa, dastur quyidagi ruxsatlarni so'raydi:

  • drive.file — foydalanuvchining Drive'ida "OfflinePOS zaxira" papkasini yaratish, unga baza zaxira nusxalarini yuklash, ularni ro'yxatlash, tiklash uchun yuklab olish va 30 kundan eski zaxiralarni o'chirish. Dastur Drive'dagi boshqa hech qanday faylni ko'ra olmaydi va o'zgartira olmaydi.
  • openid, email — qaysi akkaunt ulanganini ko'rsatish uchun.

Ma'lumotdan foydalanish

  • Zaxira nusxalar to'g'ridan-to'g'ri foydalanuvchining kompyuteridan uning o'z Google Drive'iga boradi. Ishlab chiquvchiga yoki uchinchi shaxslarga yuborilmaydi.
  • Google kirish tokeni faqat foydalanuvchi kompyuterida, Windows akkaunti kaliti bilan shifrlangan holda saqlanadi.
  • Google ma'lumotlari sotilmaydi, boshqalarga berilmaydi, reklama yoki sun'iy intellektni o'qitish uchun ishlatilmaydi.

Ruxsatni bekor qilish

  • Dasturda: Sozlamalar → "Zaxira va Google Drive" → "Uzish".
  • Istalgan vaqtda: myaccount.google.com/permissions.
  • Zaxira fayllarini Google Drive'dagi "OfflinePOS zaxira" papkasidan o'zingiz o'chirishingiz mumkin.
